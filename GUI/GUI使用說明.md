# 元智大學選課機器人GUI版 使用說明

## 重要說明

✓ 只需下載對應作業系統的執行檔（Windows 為 `.exe`，macOS 為 `.app`）即可完整使用
✓ 無需下載或準備任何其他檔案
✓ 無需安裝 Python 或任何依賴套件
✓ 完全獨立運作的單一執行程式

## 系統需求

- 作業系統：Windows 或 macOS (Intel/Apple Silicon)
- 網路連線

## 使用方式

### 1. 下載檔案

- 從 [GitHub Release 頁面](https://github.com/tsz7250/yzuCourseBot/releases) 下載對應檔案：
  - **Windows**: `YZUCourseBot-Windows.zip` (解壓後為 `元智選課機器人.exe`)
  - **macOS**: `YZUCourseBot-macOS.zip` (解壓後為 `元智選課機器人.app`)
- 建議放在容易找到的資料夾中

### 2. 執行程式

- **Windows**: 雙擊 `元智選課機器人.exe`
  - 如果 Windows Defender 出現警告，請點擊「更多資訊」→「仍要執行」
- **macOS**: 雙擊 `元智選課機器人.app`
  - **注意**：首次開啟請「右鍵點擊」並選擇「打開」，或參考 README 中的 `xattr` 指令。
- 首次執行可能需要 10-30 秒載入

### 3. 填寫資訊

```
帳號：s1234567
密碼：your_password
課程清單（每行一個）：
312,EEB219A
304,CS201B
延遲時間（秒）：2.5
```

### 4. 點擊「開始選課」按鈕

- 程式會自動登入、搜尋課程、嘗試選課
- 執行過程會顯示在下方的「執行記錄」區域

## 課程清單格式

**格式：**`系所代碼,課程代碼+班級`

**範例：**
```
312,EEB219A
304,CS201B
```

**說明：**
- 每行一個課程
- 用逗號分隔系所代碼和課程代碼
- 課程代碼包含字母和數字，最後一個字母是班級

### 如何找到代碼和課程代碼？
- 系所代碼請參考[README.md](README.md)
- 課程代碼請參考元智選課系統

## 延遲時間設定
- 延遲時間是每次選課嘗試之間的間隔
- 設定太短可能會被系統判定為異常登入
- 設定太長會降低搶課速度
- 預設值為 2.5 秒

## 常見問題

### Q1：程式執行後沒有反應？

**A1：** 首次執行需要較長時間解壓縮，請耐心等待。如果超過 1 分鐘仍無反應，請確認：
- 防毒軟體是否阻擋了程式
- 是否有足夠的磁碟空間（需要約 500MB）

### Q2：顯示「帳號或密碼錯誤」？

**A2：** 請檢查：
- Portal帳號或密碼是否正確
- 是否在選課時間內

### Q3：顯示「選課系統尚未開放」？

**A3：** 請在選課時間內使用本程式。

### Q4：顯示「Wrong coursesList, please check it again!」？

**A4：** 課程清單格式錯誤，請檢查：
- 格式是否為「系所代碼,課程代碼+班級」
- 系所代碼是否正確
- 沒有多餘的空格或符號

### Q5：顯示「異常登入，休息10分鐘!」？

**A5：** 系統偵測到異常登入行為，程式會自動等待 10 分鐘後重試。建議增加延遲時間（例如改成 3-5 秒）。

### Q6：如何停止自動選課？

**A6：** 按「暫停」鍵中止自動選課，確認後再視需要關閉視窗。

### Q7：可以同時選多個課程嗎？

**A7：** 可以，在課程清單中每行輸入一個課程即可。

### Q8：程式會一直重試直到選上課嗎？

**A8：** 是的，對於尚未成功選上的課程，程式會持續嘗試，直到：
- 成功選上
- 顯示「已選過」
- 手動關閉程式
